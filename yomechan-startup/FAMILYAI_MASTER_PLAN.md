# FamilyAI — Master Plan

> Status: Draft v0.1  
> Product name: **FamilyAI** (working title)  
> Last updated: 2026-08-03

## 1. Vision

**親が考える100のことを1に減らす。**

FamilyAIは、日々の小さく多い意思決定を支え、親子の時間と心の余裕を取り戻す「家族の第2の脳」である。最終的には、家庭ごとの価値観・状況・好みを理解し、毎日に合う次の一手を先回りして提案する、世界初の**Family OS**を目指す。

### Mission

**決断をサポートして家族の負担を減らし、親子の人生を豊かにする。**

## 2. Background / Problem

共働き家庭をはじめ、多くの親は時間にも心にも余裕がない中で、毎日たくさんの判断を迫られている。

- 今日の献立は何にするか。何を買うか。
- 子どもと何をして過ごすか。どんな言葉をかけるか。
- 親自身の時間をどうつくるか。
- 子育てに役立つ本、遊び、習い事、地域の活動は何か。

情報は世の中にあふれている一方、調べ、比較し、自分の家庭に当てはめて決める負担は親に残る。その積み重ねによって、子育てを楽しむ余白を失ってしまう家庭がある。

## 3. Target User

### Primary user

妊娠期から小学校6年生までの子どもを育てる家庭。

特に、時間・お金・相談相手の不足などから、子育てを十分に楽しめていないと感じる親を最初に助ける。

### Community user

子どもの年齢、興味、暮らし方はさまざまでも、子育てや家族の時間を楽しみたいすべての家庭。

## 4. Core Value Proposition

FamilyAIは、家庭の情報を理解したうえで、その家庭の「今日」に最適な選択肢を**理由つきで一つに絞って**提案する。提案が合わない場合は、別の候補をすぐ提示する。

親は情報収集と比較に時間を取られず、納得して行動できる。AIが決めること自体ではなく、親子が向き合う時間を増やすことが価値である。

## 5. Family Context (what FamilyAI learns)

初回登録と日々のフィードバックを通じて、次の情報を家庭ごとに理解する。

- 家族構成、子どもの年齢
- 居住エリア（詳細な住所は公開しない）
- 親と子どもの趣味、性格、好きなこと
- 子育て方針、避けたいこと
- MBTIなどの性格傾向（任意）
- 今日の空き時間、天気、場所

将来的には、提案への「よかった / 合わなかった」の反応から、家庭に合う判断を継続的に学習する。

## 6. Product Experience

### Daily decision support (MVP)

朝と夜に、その家庭向けの提案を届ける。初期の標準通知時刻は**朝7:00**と**夕方17:00**とし、各家庭が生活リズムに合わせて変更できるようにする。

| Moment | One recommended action | Example inputs |
| --- | --- | --- |
| 朝 | 今日の子どもとの過ごし方 | 天気、子どもの年齢、居住エリア、空き時間、興味、方針 |
| 朝 / 夜 | 今日の献立と買い出し | 家族構成、好み、避けたい食材、時間、予算 |
| 夜 | お風呂や寝る前の会話・接し方 | 子どもの年齢、最近の様子、親の方針 |
| 任意 | 親自身の時間をつくる提案 | 家族の予定、空き時間、家庭内の役割 |

提案には「なぜこの家庭に合うのか」を添え、親が納得して選べるようにする。

### Interest-based family community

FamilyAIは、家族同士を単に個別マッチングするのではなく、共通の興味でつながる**安全なコミュニティ**をつくる。

- サッカー好きの家族と一緒にサッカーをする
- 絵本を読む集まりに参加する
- セミを探す今日の地域コミュニティに参加する
- 日本に住む外国人家族と交流する

「近くで、あなたの家族に合いそうな活動があります。参加しますか？」というプッシュ型の提案から、ワンタップで参加できる体験を目指す。

### Community rollout

コミュニティは、まず**オンライン**で始める。関心・年齢・地域が近い家族が、テーマ別の場で交流し、FamilyAIが安全なイベント情報を提案する。参加者の信頼、地域ごとの需要、運営ルールを十分に検証できたテーマから、実際に集まるオフライン活動へ段階的に広げる。

1. オンラインのテーマ別コミュニティとイベント情報の提案
2. FamilyAIによる参加意思の確認、主催・活動ルールの検証
3. 信頼できる地域・テーマでの小規模オフラインイベント
4. 運営基準を満たした地域コミュニティへの拡大

### Initial geographic strategy

- **オンライン提供**: 全国の家庭を対象に開始する。
- **オフライン実証地域**: 愛知県・名古屋市および近隣の30〜45分程度で移動できる生活圏に限定する。
- **理由**: 創業者が愛知県在住であり、初期家族へのヒアリング、信頼できる最初の参加者集め、安全確認、活動後の改善を近い距離で行えるため。
- **次の拡大候補**: 愛知で安全性・参加率・継続率を検証後、東京23区または横浜市のような一つの大都市圏へ、一都市ずつ展開する。

### Initial community persona (MVP)

最初のオンラインコミュニティは、**名古屋圏に住む、第一子が0〜2歳の家庭**を対象にする。特に育休中・復職前後で、「今日子どもと何をするか」「献立をどうするか」「誰かとつながりたい」と感じるママ・パパを中心に、最初の30家族を募集する。

- ママ・パパのどちらも参加できる
- 毎週10分程度、提案への反応や交流に参加できる
- 遊び、親子の会話、献立のいずれかに困り感がある
- 地域の親子活動や、他の家庭を応援することに前向きな家庭も含める

孤立感だけで集めず、会話や支え合いを生む参加者を混ぜる。医療・発達に関する緊急相談の場にはせず、必要な場合は公的・専門的な相談先を案内する。

### Facilitated talk themes

FamilyAIは自由投稿を待つだけではなく、答えやすいトークテーマを毎日・毎週提示して、親が考える負担を減らしながら会話のきっかけをつくる。

| Timing | Theme | Example prompt |
| --- | --- | --- |
| 朝 | 今日の親子時間 | 「今日、親子でできたらうれしいことを一つ選ぶなら？」 |
| 夕方 | 今日の献立 | 「今日は15分でつくれるものにする？ みんなの一品を見てみる？」 |
| お風呂・寝る前 | 親子の会話 | 「今日の子どもへの一言、何にする？」 |
| 週1回 | 今週の小さな成功 | 「今週、少し楽になったこと・うれしかったことは？」 |
| 週1回 | 助けを求める | 「今週、誰かのアイデアがほしいことは？」 |
| 週末 | 地域・オンラインの活動 | 「来週、親子でやってみたいことは？」 |

各テーマには、短文入力だけでなく、選択肢・リアクション・「私も知りたい」ボタンを用意する。最初から正確な住所、子どもの写真、連絡先の共有を求めない。

## 7. MVP Priorities

1. **今日、子どもと何をするか** — 遊び・学び・会話・接し方を一つ提案
2. **一緒に遊ぶ・学ぶコミュニティ** — 興味と地域に応じた活動の発見・参加
3. **今日の献立** — 献立と買い出し内容を一つ提案

## 8. Safety Principles

子どもと家族のためのコミュニティとして、安全性は機能追加より優先する。

- 本人確認を必須にする
- 通報機能を用意し、迅速に確認・対応する
- 正確な住所など、必要以上の個人情報を公開しない
- 子どもの情報は、利用目的を限定して慎重に扱う

> Further decisions needed: コミュニティの主催者審査、初回参加時のルール、公開範囲、モデレーション体制。

## 9. Business Model Hypothesis

### Freemium model (recommended)

無料で「FamilyAIが家庭を理解し、毎日の判断を助ける」価値を体験してもらい、習慣化後に有料プランへ進むモデルを基本とする。提案価格は、**FamilyAI Plus: 月額680円（税込） / 年額5,800円（税込）**（月額換算約483円）とする。

子育て領域の比較対象には、ママリプレミアム（月額480円）、トモニテプレミアム（月額640円）、AI相談・献立・コミュニティを含むママサポートAI（月額980円）がある。FamilyAIは、情報や記事だけではなく、家庭ごとの「今日の一手」を毎日決める価値を提供するため、480円より上・980円より下の680円を初期の検証価格とする。

> Pricing validation: ベータ利用者への継続意向と、月額480円 / 680円 / 980円の価格受容性を検証してから正式価格を確定する。初期ユーザーには月額480円のFounder Priceを提供する選択肢もある。

| Plan | Value |
| --- | --- |
| Free | 基本プロフィール、週3回の「今日の一手」提案、公開コミュニティの閲覧・参加、基本的なイベント検索 |
| FamilyAI Plus | 朝・夜毎日のパーソナル提案、献立と買い出しリスト、会話・接し方の提案、代替案、夫婦で共有する家族プラン、より細かな方針設定、活動・予定を組み合わせた週末プラン |

安全に地域とつながるための基本機能（本人確認、通報、公開コミュニティへの参加）は無料に残す。課金対象は、FamilyAIが家庭をより深く理解して「決める・準備する・夫婦で共有する」ための時間削減価値とする。

### Pricing references

- ママリプレミアム: 月額480円（Google Play, 2026年7月時点）
- トモニテプレミアム: 月額640円 / 年額6,400円（App Store, 2026年8月時点）
- ママサポートAI プレミアム: 月額980円（App Store, 2026年時点）

将来的な収益の選択肢として、地域事業者・子育てサービスとの送客、信頼できるイベントの有料参加、法人の福利厚生導入を検討する。ただし、広告を優先して親の意思決定をゆがめないことを原則とする。

## 10. Product Principles

1. **一つに絞る** — 選択肢を増やさず、まず最適な一手を示す。
2. **理由を伝える** — AIの提案が家庭の状況・価値観とどうつながるかを明示する。
3. **合わなければ、すぐ次へ** — 押しつけず、代替案を軽やかに出す。
4. **家族ごとに育つ** — 使うほど、その家庭に合う第2の脳になる。
5. **安全と信頼を最優先する** — 特に子どもと地域のつながりでは、成長より安全を優先する。

## 11. Future State

FamilyAIは、献立・遊び・会話から、学び、買い物、地域とのつながりまでを横断して支える。家族が「次に何をすればいいだろう」と立ち止まる回数を減らし、そのぶん親子が笑い、話し、挑戦できる時間を増やす。

### International rollout

FamilyAIは日本でプロダクトとコミュニティの安全設計を検証した後、日本語を使う海外の家族コミュニティから展開する。

1. **米国・ロサンゼルス都市圏** — 最初の海外展開。米国には在留邦人が416,380人、ロサンゼルス都市圏には63,972人と、海外で最大の日本人コミュニティがある。日本語で始めつつ、英語対応を通じて現地家族にも広げる。
2. **オーストラリア** — 在留邦人105,566人で第2位。英語プロダクトを再利用しながら、主要都市単位で展開する。
3. **シンガポール** — 在留邦人は33,397人だが、都市国家でコミュニティ密度が高く、地域イベント型の検証に向く。
4. **中国** — 在留邦人は92,928人と大きいが、子ども・位置情報・コミュニティ情報を扱うため、中国の個人情報保護・越境データ要件に対応できる現地パートナーと体制を整えた後に検討する。

> Data source: 外務省「海外在留邦人数調査統計」（2025年10月1日現在）。
