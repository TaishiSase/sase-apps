# FamilyAI Instagram Content Kit

> Instagram launch-ready copy  
> Last updated: 2026-08-03

## 1. Profile setup

### Recommended handle

`@familyai_os`  
*空いていない場合は `@familyai.jp`、`@familyai_family`、`@familyai.app` の順で確認する。*

### Display name

`FamilyAI｜家族の第2の脳`

### Bio (copy and paste)

```text
親が考える100のことを、1に。
献立・遊び・親子の会話を、理由つきで提案する
家族の第2の脳をつくっています。
名古屋から、初期モニター30家族を準備中
```

### Account settings

- 初期は**クリエイターアカウント**にする（創業者の思いと初期モニター募集を中心に発信するため）。
- 問い合わせ先は事業用Gmailを設定するが、公開は「メール」ボタンにし、本文へアドレスを書かない。
- プロフィール画像は `assets/familyai-instagram-icon-v2.png` を使う。

## 2. First five posts

すべて、1枚目に結論を置くスライド投稿（4〜5枚）で始める。キャプション末尾の呼びかけは一つだけにする。

---

### Post 1 — FamilyAIをつくる理由

**Carousel slides**

1. `子育ての「どうしよう」を、ひとつに。`
2. `今日の献立。買い物。子どもと何をして遊ぶか。お風呂で何を話すか。`
3. `親は、毎日たくさんのことを考えて、決めています。`
4. `情報が多すぎて、決めるだけで疲れてしまう日もある。`
5. `FamilyAIは、その家庭に合う「今日の一手」を理由つきで一つ提案する、家族の第2の脳です。`

**Caption**

```text
子育てをしていると、毎日ずっと小さな意思決定の連続です。

何を食べる？
今日は何して遊ぶ？
この声かけでいいのかな？

正解を押しつけたいわけではありません。
「今日はこれでいこう」と、少し安心して決められる時間をつくりたい。

親が考える100のことを、1に。
FamilyAIを名古屋からつくり始めます。

あなたが日々いちばん決めるのが大変なこと、コメントで教えてください。
```

---

### Post 2 — 今日の一手（親子時間）

**Carousel slides**

1. `今日は、これだけでOK。`
2. `0〜2歳と、家で15分。タオルを丸めて「ころころキャッチ」。`
3. `投げる・追いかける・「どこいった？」を繰り返すだけ。`
4. `準備はいらない。うまくできなくても大丈夫。`
5. `親子で少し笑えたら、今日の遊びはもう十分。`

**Caption**

```text
何か特別な遊びをしなきゃ、と思うほど何も決められなくなる日があります。

そんな日は、タオル1枚で大丈夫。

丸める。
ころころ転がす。
「あれ、どこいった？」と探す。

15分だけでも、親子で同じものを見て笑えたら十分です。

今日は何をしよう、と迷ったら保存して使ってください。
```

---

### Post 3 — お風呂・寝る前の会話

**Carousel slides**

1. `お風呂で、子どもが話しやすくなる一言。`
2. `「今日、いちばん楽しかったのは何？」`
3. `答えられなかったら、親が先に答えてもOK。`
4. `「ママ（パパ）は、お昼の〇〇が楽しかったよ」`
5. `会話にならなくても、毎日同じ問いを置いておくだけでいい。`

**Caption**

```text
子どもとの会話は、上手に続けなくて大丈夫。

「今日、いちばん楽しかったのは何？」

答えがなくてもいい。
親が先に自分の答えを話してもいい。

会話の時間は、話すことよりも
「あなたの今日を知りたいよ」と伝える時間なのかもしれません。

今夜使うなら、保存しておいてください。
```

---

### Post 4 — 親も一人で決めなくていい

**Carousel slides**

1. `子どもが寝たあと、自分の時間はありますか？`
2. `片付け、明日の準備、調べもの。終わらないことが残っている。`
3. `「自分の時間がない」と感じるのは、がんばりが足りないからではない。`
4. `決めることが多すぎるから。`
5. `FamilyAIは、親子の時間と、親自身の余白を取り戻したい。`

**Caption**

```text
子どもが寝たあとも、親の一日は終わらない。

明日の服、献立、買い物、連絡帳、週末の予定。

自分の時間がないのは、あなたがうまくできていないからではありません。
考えて、決めて、回していることが多すぎるから。

FamilyAIは、その「決める負担」を少し減らしたいと思っています。

同じように感じる日は、「私も」で教えてください。
```

---

### Post 5 — 初期モニター募集の予告

**Carousel slides**

1. `名古屋の第一子0〜2歳家庭へ。`
2. `FamilyAIの初期モニターを、30家族募集します。`
3. `対象：名古屋圏 / 第一子0〜2歳 / 育休中・復職前後を中心に`
4. `「今日どうする？」を一緒に減らす、オンラインの小さなコミュニティです。`
5. `まずは話を聞かせてください。募集開始はこのアカウントでお知らせします。`

**Caption**

```text
FamilyAIは、最初から大きなサービスをつくるのではなく、名古屋の30家族と一緒に育てたいと思っています。

対象は、第一子が0〜2歳のご家庭。
育休中・復職前後で、毎日の小さな決断や、子育ての孤独を少し軽くしたいと感じているママ・パパを中心に考えています。

まずはオンラインから。
安心して話せる場をつくり、その先に親子で楽しめるつながりを増やしていきます。

興味がある方は、コメントかDMで「モニター」と送ってください。募集開始時にご案内します。
```

## 3. Story prompts for the first week

- 投票: `今日、いちばん迷ったのは？`（献立 / 子どもとの過ごし方 / 自分の時間 / その他）
- 質問箱: `「今日どうしよう」と思ったことを教えてください`
- 投票: `FamilyAIの初期モニター、興味ある？`（聞いてみたい / 詳しく知りたい）
- 一言: `正解を探すより、今日に合う一つを一緒に見つけたい。`
