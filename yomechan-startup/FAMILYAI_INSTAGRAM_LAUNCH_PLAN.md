# FamilyAI Instagram Launch Plan

> Status: Draft v0.1  
> Purpose: 初期モニター30家族の募集と、FamilyAIへの信頼づくり  
> Last updated: 2026-08-03

## 1. Account identity

### Recommended account name

- **Handle (first choice):** `@familyai_os`
- Fallbacks: `@familyai.jp`, `@familyai_family`, `@familyai.app`
- **Display name:** `FamilyAI｜家族の第2の脳`

`FamilyAI` は仮称のため、表示名には「家族の第2の脳」という価値を併記する。将来サービス名が変わっても、アカウントの世界観を引き継げる。

### Profile copy

```
親が考える100のことを、1に。
献立・遊び・親子の会話を、理由つきで提案する
家族の第2の脳をつくっています。
名古屋の初期モニター30家族を募集予定 ↓
```

プロフィールリンクは、初期モニター用の待機リスト（Googleフォーム等）へつなぐ。アプリ完成前は、メールアドレス・子どもの年齢帯・居住エリア（市区まで）・困っていることだけを聞き、住所や写真は集めない。

## 2. Communication principles

- 正解を教えるアカウントではなく、親の決断を軽くするアカウントにする。
- 「ママ」だけでなく、ママ・パパ・家族に届く言葉を使う。
- 不安をあおらない。できたこと、小さく楽になることを大切にする。
- 医療・発達の診断や断定的な助言はしない。心配なときは専門家・公的相談先を案内する。
- 子どもの顔、正確な居場所、家族の個人情報を投稿の前提にしない。

## 5. Cadence for the first month

- 週3投稿: 「今日の一手」1本、共感・会話1本、Founder storyまたは募集1本
- ストーリーズ: 投稿内容の投票、質問箱、初期モニターの募集状況
- コメント・DM: 24時間以内に、個人情報を求めず丁寧に返答する

## 6. Initial monitor recruitment funnel

1. Instagram投稿・ストーリーズ、または地域子育て支援拠点のチラシから待機リストへ
2. 3分以内のフォームで基本情報と困りごとを受け取る
3. 名古屋圏・第一子0〜2歳・育休中または復職前後を中心に、15分のヒアリング候補を案内する
4. ヒアリング後、最初の30家族をオンラインコミュニティへ招待する

### Suggested form fields

- ニックネーム
- メールアドレス
- 居住エリア（市区まで）
- 子どもの年齢帯（妊娠中 / 0〜6か月 / 7〜12か月 / 1歳 / 2歳）
- 今いちばん「決めるのが大変」と感じること
- 育休中・復職前後・就業中のいずれか（任意）
- 15分のオンラインヒアリングへの協力可否

## 7. Success metrics for the first 30 days

- 待機リスト登録: 30家族
- 15分ヒアリング: 10家庭以上
- 投稿への保存・コメント・DMから得た「困りごと」: 50件
- 初期コミュニティへの参加意思: 15家族以上

フォロワー数より、困りごとの具体性と、初期モニターへ進む家庭の数を重視する。
